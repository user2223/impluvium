# Design decisions

This directory records why the protocol looks the way it does, which alternatives were rejected, and which statements
of earlier design drafts this specification replaces. Decision records explain; the normative rules are in the
chapters of the specification.

| File | Content |
|---|---|
| [protocol.md](protocol.md) | Decisions on schema, encoding, signatures, keys, documents, API, events, errors and transport |

Records on the hash and chunking parameters, with the benchmark method and the freely reproducible results, are added
to this directory together with the benchmark material.
