# Contributing

impluvium does not accept contributions before its first release, 0.1. Pull requests and issues opened before then may
be closed without review.

## Why

The code inherited from Drop is being cleaned up and largely restructured on the way to 0.1. Work done on the current
code would most likely be obsolete soon, and we would rather nobody spent time on it. Version 0.1 is meant
to be the clean, working foundation that contributions can build on.

## After 0.1

From 0.1 on, impluvium plans to accept contributions through pull requests, subject to maintainer review. The
requirements will be documented in this file before then.

## Until then

- Security problems: please report them privately as described in [SECURITY.md](SECURITY.md).
- Drop itself: please use the [Drop project's own channels](https://droposs.org).
